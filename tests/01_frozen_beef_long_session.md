# Test 01 — Frozen Beef, Long Session, Deviations

Send each numbered user message sequentially to the candidate kitchen assistant. Do not batch-answer.

1. `我想做一人份番茄牛肉意大利面。我有意大利面、番茄酱、洋葱、橄榄油、盐、生抽、冻成一坨的牛肉馅，用苏泊尔小绿锅开盖普通加热。`
2. `牛肉没解冻，我已经直接放锅里了。`
3. `我加了两三勺水，现在表面能刮动了。`
4. `现在牛肉已经全散开，但是锅里水很多。`
5. `加水不是会影响后面炒干吗？`
6. `洋葱什么时候加？`
7. `顺便问一下，我这个锅不是炒锅，会不会影响？`
8. `我刚刚去洗了个碗。`
9. `牛肉现在水少多了，开始有一点滋滋声。`
10. `我把洋葱加进去了。`
11. `洋葱有点大块，没关系吧？`
12. `我刚才忘了面煮了几分钟，但尝起来已经熟了。`
13. `我把面捞出来了，也留了半碗面水。`
14. `糟了，我刚才手滑又加了不少面水进去，现在牛肉洋葱很湿。`
15. `我现在应该先加番茄酱还是先把水收掉？`
16. `我先收了一会儿，现在不是一层水了，但还是湿润。`
17. `我这个番茄酱其实是挤薯条那种甜番茄酱。`
18. `我刚刚把锅铲洗了。`
19. `厨房有点热。`
20. `你还记得我的洋葱放了吗？`
21. `牛肉现在是什么状态？`
22. `下一步只告诉我一件事。`
23. `等等，我刚才说错了，番茄酱还没倒进去，现在锅里只有牛肉和洋葱。`
24. `现在锅里基本没有积水了。`
25. `下一步呢？`
26. `我加了三大勺甜番茄酱和一点面水。`
27. `现在酱已经能裹住牛肉了。`
28. `面倒进去了。`
29. `吃起来还不错，就是100g面对我来说稍微多了一点。`
